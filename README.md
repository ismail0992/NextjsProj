# Alex Morgan Portfolio

A responsive portfolio built with the Next.js App Router. It includes Home, About, Projects, and Contact routes. The route pages are Server Components and can be deployed to Vercel or another Node.js hosting platform.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Use `npm run build` to create the production build and `npm run start` to serve it locally.

## Deploy

Import this project into [Vercel](https://vercel.com/new), or connect the repository through the Vercel CLI. Vercel detects Next.js and configures the build automatically. For another Node.js host, use `npm run build` followed by `npm run start`.

## Personalize

Update the name, bio, contact email, social links, and project details in `app/`. Replace the example Unsplash image URLs with your own work and portrait. Global styling lives in `app/globals.css`.
